# auditframe

Audit lightweight frame statistics from stdin samples.

**Site:** https://theworker02.github.io/auditframe/

## Install / run

```bash
git clone https://github.com/theworker02/auditframe.git
cd auditframe
node src/cli.js
node --test
```
